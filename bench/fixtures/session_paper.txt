Shannon's mathematical theory of communication treats a message as one selection from a set of possible messages. The information content of that selection is the negative logarithm of its probability, so rarer messages carry more information. A discrete channel is a system that transmits a sequence of symbols from a finite alphabet. Each transmitted symbol may be received correctly or may be altered by noise. Channel capacity is the supremum of transmission rates at which the probability of error can be driven toward zero by coding.

A code maps messages onto longer sequences of channel symbols. Redundancy in those sequences lets a decoder reject some of the patterns that noise could produce. The noisy channel coding theorem says that for any rate below capacity there exists a code whose error probability vanishes as block length grows. The proof is non-constructive: it shows that a random ensemble of codes performs well on average, so at least one code in the ensemble is good. Finding an explicit code that meets the bound is a separate engineering problem.

Mutual information between input and output quantifies how much uncertainty about the input is removed by observing the output. When the channel is noiseless, mutual information equals the entropy of the input. When the channel is useless, mutual information is zero. Capacity is the maximum of that mutual information over input distributions. For a binary symmetric channel the maximizing input is uniform, and capacity is one minus the binary entropy of the crossover probability.

Practical systems operate far from these limits. They use convolutional codes, low-density parity-check codes, or polar codes, then iterate between detection and decoding. The gap to capacity is measured in decibels of signal-to-noise ratio at a target bit error rate. Closing that gap costs latency, silicon area, and energy per bit. Designers trade those costs against the information rate the application actually needs.
